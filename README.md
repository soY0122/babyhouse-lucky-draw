# 창원베이비하우스 행운 추첨 🎀

CHANGWON BABYHOUSE LUCKY DRAW — 공정한 가중치 기반 추첨 웹 애플리케이션 (React + TypeScript + Vite).

## 실행 방법 (How to Run)

### 개발 서버 실행 (Dev server)

```bash
cd babyhouse-lucky-draw
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 열면 앱이 실행됩니다.

### 프로덕션 빌드 (Production build)

```bash
npm run build
# 결과물은 dist/ 폴더에 생성됩니다
npm run preview  # 빌드 결과 미리보기
```

## 기능 요약 (Features)

- **공정한 가중치 기반 추첨**:
  - `crypto.getRandomValues()` 기반의 비트 거부 샘플링(Rejection Sampling)을 통해 모듈로 편향(Modulo bias) 없는 정밀 난수 생성.
  - 응모권 수에 정비례하는 공정한 가중치 누적합 및 이진 탐색 알고리즘.
  - 1인 1티켓 보유 시 중복 당첨 불가 및 물리적 티켓 1회 1매 소진 보장.
- **서스펜스 슬롯 머신 애니메이션**:
  - 고속 회전 → 단계별 감속 → 막판 서스펜스 크롤 → 당첨자 정확 일치 정지.
  - 단일 수직 릴 구조로 당첨자 이름 및 기호(마스킹) 100% 일치 표기.
  - 1배속 / 2배속 / 3배속 애니메이션 속도 조절 지원.
- **당첨 기록 및 안전성**:
  - 전체 추첨 애니메이션이 완전히 끝난 후 최종 당첨 기록 일괄 반영.
  - 당첨 당시 보유 응모권 수 스냅샷 영구 기록.
  - IndexedDB 트랜잭션을 통한 브라우저 영구 보관 및 새로고침 복구 안전성.
  - CSV 및 텍스트 클립보드 복사 지원.

## 데이터 입력 형식 (Input Format)

```
이름*응모권수
```

- 줄 단위로 참가자를 한 명씩 입력합니다.
- 마지막 `*숫자`가 해당 참가자의 응모권 수입니다.
- 수량을 생략하면 1장으로 자동 처리됩니다.
- 참가자 데이터를 교체하거나 새로고침해도 기존 당첨 기록은 안전하게 보존됩니다.
